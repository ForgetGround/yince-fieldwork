# 银策编译器 · 展业版

面向小微客户经理的可解释 AI 展业工作台原型：把产品制度转成可核查规则，把客户业务特征转成有依据的联系建议，再把拜访记录整理成跟进任务。

**[在线体验 → yince.xcoria.cn](https://yince.xcoria.cn/)** · [部署与隔离说明](deploy/README.md)

本仓库为可交互参赛演示，内置 20 位模拟客户。当前使用确定性规则和文本提取模板，没有接入大模型、银行生产系统或真实授信审批。

## 解决什么问题

客户经理每天面对大量客户和不断更新的制度，需要回答：今天先联系谁、依据是什么、可以谈什么业务、还缺哪些信息、下一步如何跟进。

银策把这条工作流放进同一个工作台，并让每一步可以回看依据：

```mermaid
flowchart LR
    A[制度与产品资料] --> B[候选规则与来源]
    B --> C[人工确认与版本管理]
    C --> D[客户机会排序]
    D --> E[访前作战单]
    E --> F[拜访纪要草稿]
    F --> G[人工确认与跟进任务]
    C --> H[操作审计与历史快照]
    G --> H
```

## 核心功能

| 模块 | 当前可以体验的内容 |
| --- | --- |
| 政策规则库 | 查看原文出处、演示版本冲突、人工确认新规则、归档旧版本；从简单文本提取候选经营年限规则 |
| 客户机会 | 20 位模拟客户按可复算权重排序；按编号、行业和机会筛选；导入字段白名单 JSON |
| 访前作战单 | 联系原因、数据证据、产品线索、三态条件核查、未知信息、访谈问题与材料清单 |
| 访后闭环 | 从记录中摘取纪要、编辑并确认、建立跟进任务、导出 CRM JSON |
| 合规与审计演示 | 建议确认、来源追溯、版本快照、操作记录；不输出授信审批结论 |

例如：KH-001 的经营贷款将在业务基准日后 45 天到期，近期结算稳定，拜访记录提到采购计划。作战单会同时展示这些证据，并提醒客户经理核实实际续贷及流动资金需求。

## 五分钟演示

1. 从侧栏打开“政策规则库”，点击“原文依据”。查看截图来源与字段表达式，或在“附件产品库”查看 ET 工作表单元格出处。
2. 处理经营年限从 1 年调整为 2 年的模拟通知。勾选人工确认后生效，旧规则归档。KH-004 等经营 1.5 年的客户核查随之变化。
3. 打开“客户机会”。查看 20 位客户排序，搜索编号 / 行业或按机会类型筛选。支持 JSON 导入、字段白名单、重复编号校验、未知值保留与合并。
4. 打开 KH-001 的访前作战单，查看 45 天到期、采购计划等证据，核对规则与未知信息。确认建议后进入拜访记录。
5. 填入模拟拜访记录，生成待确认纪要，人工核对及编辑后保存，自动创建跟进任务。可导出 CRM JSON，并查看操作审计及历史规则快照。

## 能力与边界

这是浏览器内的业务规则与模板演示。客户 / 规则 / 任务 / 纪要 / 操作记录保存在当前网站来源下的浏览器 localStorage，刷新后保留；不同设备、域名和浏览器不共享。清除站点数据会重置本地记录。固定业务基准日为 2026-09-15，实际审计操作记录当前时间。

- 客户优先级是演示权重之和，上限 100。未知特征不加分；得分不表示授信结论或审批概率。
- 条件核查采用符合 / 暂未满足 / 待核实三态，产品规则变化不把客户自动拒贷。
- TXT / Markdown 候选规则编译器仅处理明确“满 / 不少于 / 至少”的简单经营年限条件，拒绝歧义上限、严格不等式、复合例外。其他段落保留人工整理，不宣称已全面解析。
- Word、PDF、ET 的通用上传解析尚未接入，需先提取成文本；给定 ET 附件已完成离线提取并内置。
- 拜访纪要使用可审查的原文句子提取，未提及内容留空；人工可编辑并确认。没有自动写入 CRM。
- VPS 演示站公开访问，请使用模拟数据。应用内日志和角色均为演示，不具备真实身份认证、服务端防篡改、持久数据库、角色权限或生产合规能力。
- 正式接入需要文档解析 / OCR / LLM 结构化提取、经授权脱敏数据、规则审核工作流、服务端版本与审计存储、身份权限和银行 CRM 接口。

## Agent 工具

支持 `document.modelContext` 时注册 `list_customer_opportunities`（只读）与 `open_customer_brief`（打开并记录查看）。工具不确认规则或建议、不执行审批。无 WebMCP 的浏览器仍可操作完整界面。

## 部署方式

演示站运行在新加坡 VPS：专用 `yince-web` 系统账号、独立 `yince.service`、独立只读发布目录、回环端口 `59603`，设置 CPU / 内存 / 进程数上限。公网仅通过独立域名的 HTTPS 入口访问，使用独立证书。详细配置、更新和回滚见 [部署说明](deploy/README.md)。

服务器的公网 Nginx 入口和操作系统仍与其他项目共享；这是进程、权限和资源层面的隔离，并非独立虚拟机。浏览器数据也由 `https://yince.xcoria.cn` 的来源边界与其他站点区分。
