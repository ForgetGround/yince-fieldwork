# 企业名称字段验收

- 企业与客户信息的首行显示企业名称，详细作战单共用同一组件；缺失时显示“待补充”。
- 访前／访后客户选择、客户列表及产品匹配列表展示企业名称；客户与产品匹配搜索支持名称。
- 客户 JSONB 支持可选 `companyName`，导入去除首尾空格并限制 1–120 字；旧模板或 null 不清空已有名称，模拟模板显式标注“模拟”。
- 企业名称不自动加入外部 AI 的客户业务摘要；已有最小化上下文测试增加企业名称断言。

## 验证结果

- 37 项单元测试通过，生产构建与 TypeScript 检查通过。
- 独立 `yince_test` PostgreSQL 测试通过：仅补齐缺名原始种子、保留原字段和已有名称、跳过导入与已变更行业客户、重复运行无变更、导入保存、旧模板保留名称、只读身份拒绝导入。测试数据在事务中回滚。
- 线上 20 位模拟客户由 0 个名称补齐为 20 个；迁移前后排除 `companyName` 的客户载荷校验值完全一致。
- 浏览器确认 KH-001 首行名称可见，切换 KH-020 后主页面与详细作战单名称一致；按“商务示例企业020”搜索得到对应客户。
- 手机 390 × 844 无横向溢出，浏览器未出现控制台错误。
