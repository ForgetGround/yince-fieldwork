# 展业助手对话界面验收（2026-09-30）

## 交付

- 首页按参考图调整为侧栏导航、自然语言对话、内联方案和底部输入框。
- 默认 DeepSeek Flash 简洁回答，自然语言要求营销方案时输出沟通目标、重点询问、资料准备、后续动作。
- 支持连续追问、改写话术、发起新对话；页面切换保留当前会话。

## 验证

- `npm run build:vps`：通过（生产静态导出与 TypeScript 检查）。
- `npm test`：34 项通过，增加连续追问的客户定位、明确切换客户、越权历史不恢复数据的测试。

- 新增助手及服务端文件通过 ESLint；`app/page.tsx` 原有 refs、set-state-in-effect 两项错误在改动前版本也存在，未扩展本次修改范围。
