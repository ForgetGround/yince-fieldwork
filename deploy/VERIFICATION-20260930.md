# 2026-09-30 对话式首页验收

## 已发布

- 前端、API：`20260930-chat`；AI 适配服务同版本，独立用户／进程／目录／私有 socket。
- 地址：https://yince.xcoria.cn/。
- 模型：实际可用的 `deepseek-flash`，关闭 thinking，默认简洁回答；另一模式为“生成方案”。
- 页面顶部：跟进进度、大字号待办、待审查数量和优先项目；下方对话、方案卡片和对应业务页入口。

## 检查结果

- 单元测试 27 项通过；类型检查和 Next.js 静态构建通过。
- AI API 集成测试 6 项（包含父测试）通过，使用 `yince_test` 库和模拟 provider：匿名／CSRF／跨空间／其他用户对话拒绝，输入模型注入拒绝，非法跳转过滤，失败恢复，客户权限变化使旧对话失效，同一对话并发拒绝。
- 本地真实 Flash 调用可生成 KH-001 方案；浏览器展开步骤及政策依据，点击“查看税易贷”进入对应产品详情。
- 手机 390×844 布局可操作；桌面线上首页、进度、大数字、聊天输入和待办跳转检查通过。
- 线上真实模型简洁回答及私有历史读取成功；单次问候实测约 1.6 秒（含网络及保存，不作为性能承诺）。
- 生产账户沿用已有管理员，未增删账户；未修改业务客户、产品、规则或任务。
- 发布前数据库已备份，迁移 003 成功。旧 API／前端版本保留可回滚，新表兼容旧服务。
- 原业务 API 仍只允许 AF_UNIX，网络全部禁止；仅 AI 适配进程拥有对外模型连接与服务器端密钥。
- `/etc/yince-ai.env` 为 root:root 0600，私有 socket 为 yince-ai:yince-api 0660。
- `xcoria-orders`、`sing-box`、`clash-subscription` 发布前后 PID 未变化；共享 Nginx、原站点和原服务配置摘要未变化。

## 当前边界

- AI 草稿需人工核实；不会自动写入业务、审批、发送通信或跳转任意外部 URL。
- 没有流式输出；15 秒 provider 超时会明确提示重试。
- 客户摘要最多 15 位，用户明确提及的有权客户优先。详细原始记录、联系方式和坐标不作为模型上下文。
- 配额每用户每分钟 8 次、每空间每天 200 次；适配服务并发 2。
