# 高德地图接入配置

## 当前可用

首页地图服务支持登记客户经营区域、地址和 GCJ-02 经纬度，位置保存到客户 JSONB；仅管理员、网点负责人／主管、负责该客户的客户经理可以维护。只读成员和审查员的客户与访前快照响应移除精确位置。关闭地图授权可继续内部保存地址，但不显示为高德标记、不允许发起导航。

区域筛选与直线距离计算不调用外部接口。距离中心是首页选中的已登记客户，不是设备当前位置。未登记位置不参与距离筛选。

一键导航使用后端鉴权的 `customer.navigate` 指令，保存导航审计后返回 `https://uri.amap.com/navigation` 链接。参数仅包含经纬度、通用目的地标签、出行方式和来源，不传客户编号或融资信息。手机尝试拉起高德 App；电脑端打开网页后可能需要指定起点。弹窗被阻止时保留手动打开链接。

## 嵌入地图（待真实 Key 联调）

在构建前设置：

```dotenv
NEXT_PUBLIC_AMAP_WEB_KEY=银行或项目自己的Web端JS_Key
NEXT_PUBLIC_AMAP_SERVICE_HOST=https://已配置的安全代理域名/_AMapService
```

JS Key 为浏览器公开标识，须配置域名白名单与额度限制。**安全密钥 jscode 不得放在 NEXT_PUBLIC 变量、仓库或静态页面中**，应由固定上游的安全代理添加。不得把用户输入作为代理目标，防止开放代理／SSRF。

当前生产环境没有配置上述字段，不会加载第三方地图 SDK。没有 Key 时不妨碍位置登记、筛选和 URI 导航。界面不将空白底图伪装为已接入地图。

采用按需加载 JS API 2.0，加载失败／12 秒超时可继续使用外部导航；组件卸载销毁地图。地图仅添加获得地图授权的地点标记，标记点击切换客户。开启地图前须完成真实 Key、域名、安全代理、CSP 与设备联调；当前仅构建和无 Key 路径经过验证。

## 隔离部署建议

现有银策 API 只允许 Unix socket，不为地图功能解除出站限制。安全代理放在独立适配器或固定 Nginx location／上游，沿用专属域名、独立凭据、限流与访问日志。不要把整个 `/api` 代理开放到外网。具体代理配置遵循官方安全密钥文档，Key 到位后再安装验证。

- 地址转经纬度、WGS84／BD09 到 GCJ-02 转换：尚未接入。
- 设备当前位置定位、框选辖区、多站路线优化：尚未接入。
- 大规模空间查询：后端先鉴权，再范围查询和分页；坐标系须明确，GCJ-02 不能冒充 EPSG:4326。
- 第三方脚本隔离：正式银行场景宜部署独立受限地图页面／域名，通过最小消息协议传坐标。
