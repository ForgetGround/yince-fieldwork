# 设计模板选型与适配

## 选择

采用 **shadcn/ui 官方 Dashboard-01（New York / Tailwind v4）** 的侧栏、主内容框架和 SectionCards 卡片结构，适配现有银策 Next.js 项目。

- 官方模板：https://ui.shadcn.com/blocks
- 模板注册文件：https://ui.shadcn.com/r/styles/new-york-v4/dashboard-01.json
- GitHub：https://github.com/shadcn-ui/ui
- 许可：MIT，原许可保留在 `vendor/shadcn-ui-LICENSE.md`。
- 调研日期：2026-09-29。

## 比较

| 方案 | 适配判断 |
| --- | --- |
| shadcn/ui Dashboard-01 | 已有相同组件基础；侧栏、卡片、表格模式直接复用；采用 |
| Kiranism/next-shadcn-dashboard-starter | Next.js + shadcn，MIT；完整 starter 带 Clerk、分析等集成，当前仅需设计适配，未引入 |
| TailAdmin Next.js Free | 可作为完整后台起点；已有组件需额外迁移，当前未引入 |

来源：https://github.com/Kiranism/next-shadcn-dashboard-starter ，https://github.com/TailAdmin/free-nextjs-admin-dashboard 。未下载或使用付费模板资源。

## 实际复用

- `app/page.tsx`：Dashboard-01 的 SidebarProvider → inset Sidebar → SidebarInset → header/content 结构；按展业、协作与管理分组导航。
- 访后待办统计统一在 `components/followup-board.tsx` 中展示，保留大字号数字；访前页面专注客户信息与沟通准备，不再放置跨阶段的待办卡片。
- `app/dashboard-theme.css`：银策主题，蓝色主色、灰白背景、统一边框、间距、字号与表单；状态色保留业务含义。
- `components/brand-logo.tsx`、`public/yince-logo.svg`、`public/favicon.svg`：原创 SVG 标志，Y 的分支汇合表示规则转成行动路径；作为代码矢量资源，无额外图片加载依赖。
- 登录、权限、数据库、产品匹配与渠道逻辑沿用现有实现；没有新增 npm 运行依赖、外部认证或遥测服务。

这次采用模板布局及组件模式，不是把模板的演示业务、数据与认证整套覆盖。

## 验证

类型检查与 VPS 静态构建；浏览器检查首页、产品库、客户详情、导航开合、登录及手机布局。发布仅更新银策静态 release，后端与数据库不变。
